FAYE PORTFOLIO - responsive static site (no install, no build)

FILES
  index.html   page structure
  styles.css   all styling (dark + light theme, mobile layout)
  script.js    projects, skills, theme toggle (edit your content at the top)

BEFORE YOU PUBLISH - copy these from your old project's public/ folder into this folder:
  faye.png                 your portrait
  og.jpg                   social preview image
  logos/                   html.png css.png javascript.png react.png gsap.png supabase.png
                           git.png github.png vscode.png cloudflare.png
  images/                  project screenshots (already included)
  resume.pdf               your resume (the Resume button links to it)

PUBLISH ON GITHUB PAGES
  1. Put everything in a repo (for example "portfolio") and push to GitHub.
  2. Settings > Pages > Deploy from branch > main > / (root).
  3. Open https://YOURNAME.github.io/portfolio/ and hard refresh.

TEST LOCALLY
  Open index.html in a browser, or run:  python3 -m http.server  then visit http://localhost:8000
